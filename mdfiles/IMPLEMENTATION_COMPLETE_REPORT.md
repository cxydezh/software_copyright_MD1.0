## ✅ 已实现的功能

### 1. 员工账号注册功能
- **注册页面更新**：添加"我是公司员工，申请员工账号"复选框
- **申请理由填写**：员工账号需要填写申请理由
- **双重注册支持**：支持员工账号和普通用户两种注册模式
- **邮箱唯一性**：确保邮箱在User和Staff表中的唯一性

### 2. 系统管理员审核功能
- **用户管理模块**：在右上角下拉菜单中为系统管理员提供"用户管理"功能
- **权限控制**：只有系统管理员权限才能看到和访问该模块
- **审核操作**：支持审核通过和驳回员工账号申请
- **审核记录**：记录审核者、审核时间和审核备注

### 3. 权限分配功能
- **默认权限**：审核通过时自动分配"普通业务员"权限
- **权限调整**：支持为员工分配不同权限级别
- **权限类型**：普通业务员、项目执行者、系统管理员、论文编辑、专利编辑、专家

### 4. 登录限制功能
- **状态检查**：登录时检查员工账号审核状态
- **访问控制**：未审核通过的员工无法进入工作台
- **用户提示**：显示相应的状态提示信息


### 审核状态
- `pending`: 待审核（默认状态）
- `approved`: 已审核通过
- `rejected`: 已驳回

- 支持多种权限级别
- 权限与功能模块关联

## 📋 使用流程

### 员工注册流程
1. 访问注册页面：`http://localhost:5000/auth/register`
2. 勾选"我是公司员工，申请员工账号"
3. 填写申请理由
4. 提交注册申请
5. 等待系统管理员审核

### 管理员审核流程
1. 使用系统管理员账号登录：`admin@yiqichuang.com` / `admin123`
2. 点击右上角下拉菜单中的"用户管理"
3. 查看待审核员工账号列表
4. 选择审核通过或驳回
5. 如通过，可进一步分配权限

### 员工使用流程
1. 员工账号审核通过后可以正常登录
2. 根据分配的权限访问相应功能模块
3. 未审核通过的员工会看到相应提示
