# 项目结清状态重构说明

## 修改概述

根据用户需求，将"已结清"状态从项目的线性状态流程中分离出来，改为独立的标记字段，使其可以与其他业务状态共存。

## 主要变更

### 1. 数据库模型变更 (`database/models.py`)

- **新增字段**: `is_settled` (Boolean) - 表示项目是否已结清
- **保留字段**: `settle_time` (DateTime) - 记录结清时间
- **修改字段**: `status` 枚举中移除 `'已结清'`

**新的状态流程**:
```
待确认 -> 已确认 -> 已立项 -> 执行中 -> 已完成 -> 已上传 -> 已获取流水号 -> 证书完成 -> 已归档
```

**结清状态**: 作为独立标记，可与以上任何状态共存

### 2. 业务逻辑变更

#### 结清操作
- **新增路由**: `/staff/project/<int:project_id>/settle` - 标记项目为已结清
- **新增路由**: `/staff/project/<int:project_id>/unsettle` - 取消结清标记
- 业务员和执行者都可以标记结清
- 已归档的项目不能取消结清

#### 归档限制
- **重要**: 项目必须先标记为"已结清"才能归档
- 尝试归档未结清的项目时会返回错误提示

### 3. 前端界面变更

#### 项目详情页 (`templates/staff/project_detail.html`)
- 在项目基本信息中显示结清状态徽章
- 添加独立的"标记为已结清"按钮
- 已结清的项目显示"取消结清标记"按钮（已归档除外）
- 状态选择下拉框中移除"已结清"选项
- 归档选项添加提示"(需先结清)"

#### 项目进度页 (`templates/project_status.html`)
- 在页面顶部显示结清状态徽章
- 项目信息区域显示结清状态和时间
- 状态流程中移除"已结清"步骤
- 归档状态说明中显示是否已结清

#### 执行者项目列表 (`templates/staff/assigned_projects.html`)
- 状态筛选器中移除"已结清"选项

### 4. API 变更 (`web_app/views/api.py`)

- 项目状态统计中移除"已结清"状态
- 新增独立的结清状态统计:
  - `已结清`: 所有 `is_settled=True` 的项目数量
  - `未结清`: 所有 `is_settled=False` 的项目数量

### 5. 统计数据变更 (`web_app/views/staff.py`)

业务员仪表板统计中新增:
- `settled_count`: 已结清的项目数量

## 数据迁移

### 迁移脚本

运行 `migrate_settled_status.py` 脚本：

```bash
python migrate_settled_status.py
```

脚本会自动:
1. 添加 `is_settled` 列
2. 将现有 `status='已结清'` 的项目设置为 `is_settled=True`
3. 将这些项目的状态改为 `'证书完成'`

### 注意事项

#### SQLite
需要手动操作:
1. 备份数据库文件
2. 删除旧数据库
3. 运行 `python init_sqlite.py` 重新创建数据库
4. 使用数据迁移工具恢复数据

#### MySQL
需要手动修改枚举类型:
```sql
ALTER TABLE projects MODIFY COLUMN status 
ENUM('待确认', '已确认', '已立项', '执行中', '已完成', '已上传', 
     '已获取流水号', '证书完成', '已归档') DEFAULT '待确认';
```

## 使用说明

### 结清流程

1. 项目可以在任何阶段标记为已结清
2. 通常在"证书完成"后标记结清
3. 归档前必须标记为已结清

### 界面操作

#### 标记结清
1. 进入项目详情页
2. 点击"标记为已结清"按钮
3. 确认操作

#### 取消结清（仅限未归档项目）
1. 进入项目详情页
2. 点击"取消结清标记"按钮
3. 确认操作

#### 归档项目
1. 确保项目已标记为结清
2. 在状态选择器中选择"已归档"
3. 点击"更新状态"

## 常见问题

### Q: 为什么要将"已结清"从状态中分离？
A: 因为结清是一个独立的财务标记，可能在项目的不同阶段发生，不应该作为线性状态流程的一部分。

### Q: 已归档的项目可以取消结清吗？
A: 不可以。已归档的项目是最终状态，不应该修改其结清标记。

### Q: 项目可以在未完成时就标记结清吗？
A: 技术上可以，但业务流程建议在证书完成后再结清。

### Q: 迁移会丢失数据吗？
A: 不会。迁移脚本会保留所有现有数据，只是将"已结清"状态转换为新的字段表示。
