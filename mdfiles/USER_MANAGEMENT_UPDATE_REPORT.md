## 🎨 用户界面

### 页面布局
1. **未审核员工列表**
   - 显示申请时间、申请理由
   - 提供"通过"和"驳回"操作按钮

2. **正式员工列表**
   - 显示权限状态、审核状态
   - 已通过员工：显示"分配权限"按钮
   - 已驳回员工：显示"重新申请"和"取消申请"按钮

3. **普通用户列表**
   - 显示用户类别、验证状态
   - 仅供查看，无操作功能

### 操作流程
1. **审核流程**：未审核 → 通过/驳回
2. **重新申请流程**：已驳回 → 修改理由 → 重新申请 → 待审核
3. **取消申请流程**：已驳回 → 确认取消 → 删除记录
4. **权限分配流程**：已通过 → 选择权限 → 分配完成

## 🚀 使用指南

### 访问方式
1. **管理员登录**：`admin@yiqichuang.com` / `admin123`
2. **访问用户管理**：`http://127.0.0.1:5000/staff/user_management`

### 操作说明
1. **审核员工申请**：
   - 在"未审核员工列表"中查看申请
   - 点击"通过"或"驳回"按钮
   - 驳回时需要填写驳回原因

2. **管理已驳回员工**：
   - 在"正式员工列表"中查看已驳回员工
   - 员工可以选择"重新申请"或"取消申请"
   - 重新申请需要填写新的申请理由

3. **分配权限**：
   - 在"正式员工列表"中为已通过员工分配权限
   - 支持6种权限级别选择
