## 🚀 使用流程

### 被驳回员工登录流程
1. **用户登录**: 使用员工账号登录
2. **状态检查**: 系统检测到审核状态为'rejected'
3. **自动重定向**: 重定向到 `/auth/handle_rejected_staff`
4. **信息展示**: 显示驳回原因和申请信息
5. **操作选择**: 用户选择重新申请或取消申请

### 重新申请流程
1. **点击重新申请**: 打开重新申请模态框
2. **填写新理由**: 根据驳回原因修改申请理由
3. **提交申请**: 系统更新状态为'pending'
4. **重定向登录**: 返回登录页面等待审核

### 取消申请流程
1. **点击取消申请**: 打开取消申请确认模态框
2. **确认操作**: 用户确认要取消申请
3. **删除记录**: 系统删除员工账号信息
4. **自动登出**: 用户被登出并重定向到登录页面
