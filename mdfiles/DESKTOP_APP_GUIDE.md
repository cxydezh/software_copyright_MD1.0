# 软著管理系统桌面应用使用指南

## 概述

根据需求分析文档重新设计的桌面应用，采用MVC架构实现前后端分离，为项目执行者提供便捷的软件著作权登记材料编辑环境。

## 功能模块

### 1. 任务视图 (Task_view)

**功能定位**：主要用于项目文件创建、流水号获取、项目管理。

**界面布局**：
- 左侧：项目列表（已立项、执行中、已完成）
- 右侧：项目详情和控制按钮

**主要功能**：
- 项目状态管理（已立项 → 执行中 → 已完成）
- 项目文件夹创建
- 文件管理（上传、下载、预览、删除）
- 材料文件选择（身份证、证书、合同）
- 流水号获取和管理

**操作流程**：
1. 选择项目 → 查看详情
2. 创建项目文件夹
3. 选择相关材料文件
4. 更新项目状态

### 2. 模板管理 (models_manage)

**功能定位**：提供对软著申请文档模板的管理功能。

**界面布局**：
- 左侧：模板列表
- 右侧：模板详情和操作按钮

**主要功能**：
- 模板文件夹管理
- 模板信息编辑（编程语言、IDE、数据库类型等）
- 通过模板创建项目
- 模板文件CRUD操作

**操作流程**：
1. 添加模板文件夹
2. 编辑模板信息
3. 保存模板配置
4. 通过模板创建新项目

### 3. 材料管理 (material_manage)

**功能定位**：提供对软著申请材料的管理功能。

**界面布局**：
- 左侧：材料类型选择和文件列表
- 右侧：材料详情表单

**材料类型**：
- 身份证复印件
- 统一社会信用代码证书
- 合同模板

**主要功能**：
- 材料文件上传和管理
- 材料信息编辑
- 材料分类存储
- 文件信息CRUD操作

**操作流程**：
1. 选择材料类型
2. 添加材料文件
3. 编辑材料信息
4. 保存材料数据

### 4. 系统设置 (System_setting)

**功能定位**：提供对系统路径和配置的管理。

**主要设置**：
- 项目模板文件夹路径
- 身份证复印件文件夹路径
- 统一社会信用代码证书文件夹路径
- 合同文件夹路径
- 数据库路径
- 网站链接配置

**操作流程**：
1. 浏览选择文件夹路径
2. 配置数据库连接
3. 设置网站链接
4. 保存配置
5. 测试连接

## Dialog窗口

### 1. 身份证复印件Dialog

**界面布局**：
- 左侧：所有身份证文件列表
- 中间：最近添加的10个文件
- 右侧：文件详情表单

**功能**：
- 文件浏览和选择
- 文件详情查看
- 双击快速选择
- 文件信息编辑

### 2. 统一社会信用代码证书Dialog

**界面布局**：同身份证Dialog

**功能**：
- 证书文件管理
- 机构信息编辑
- 有效期管理
- 法人代表信息

### 3. 合同文件Dialog

**界面布局**：同身份证Dialog

**功能**：
- 合同文件管理
- 合同信息编辑
- 参与人类型管理
- 合同详情查看

## 数据库结构

### 本地SQLite数据库表

1. **default_paths** - 默认路径表
2. **id_card_files** - 身份证复印件表
3. **usccc_files** - 统一社会信用代码证书文件表
4. **contract_files** - 合同文件表
5. **template_files** - 项目模板表
6. **project_files** - 项目文件表
7. **local_projects** - 本地项目表

## 使用说明

### 启动应用

```bash
python run_desktop.py
```

### 首次使用

1. 进入"系统设置"模块
2. 配置各个文件夹路径
3. 测试数据库连接
4. 保存配置

### 日常使用

1. **项目管理**：
   - 在"任务视图"中查看项目列表
   - 选择项目查看详情
   - 创建项目文件夹
   - 管理项目文件

2. **材料管理**：
   - 在"材料管理"中添加各类材料
   - 编辑材料信息
   - 在任务视图中选择材料文件

3. **模板管理**：
   - 在"模板管理"中添加项目模板
   - 编辑模板信息
   - 通过模板创建新项目

## 技术特性

- **MVC架构**：清晰的代码结构，便于维护
- **SQLite数据库**：本地数据存储，无需网络连接
- **模块化设计**：各功能模块独立，便于扩展
- **用户友好**：直观的界面设计，操作简单
- **文件管理**：完整的文件上传、下载、预览功能
- **数据同步**：支持与服务器数据同步

## 注意事项

1. 首次使用前请先配置系统设置
2. 确保各文件夹路径存在且有写入权限
3. 定期备份本地数据库
4. 文件上传时注意文件大小限制
5. 建议定期同步服务器数据

## 故障排除

### 常见问题

1. **应用无法启动**：
   - 检查Python环境和依赖包
   - 确认数据库文件权限

2. **文件上传失败**：
   - 检查目标文件夹权限
   - 确认文件大小未超限

3. **数据库连接失败**：
   - 检查数据库文件路径
   - 确认SQLite支持

4. **界面显示异常**：
   - 检查系统字体设置
   - 确认显示分辨率
