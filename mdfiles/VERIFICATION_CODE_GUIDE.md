# 验证码功能使用指南

## 功能概述

系统已升级邮箱验证功能，现在使用**6位数字验证码**进行邮箱验证，替代了之前的链接验证方式。

### 主要特性

- ✅ **6位数字验证码** - 简单易记
- ✅ **5分钟有效期** - 安全可靠
- ✅ **美观邮件模板** - 兼容各种邮箱客户端
- ✅ **实时倒计时** - 用户友好的界面
- ✅ **自动重新发送** - 60秒后可重新发送
- ✅ **输入验证** - 自动格式化输入

## 功能流程

### 1. 用户注册流程

```
用户填写注册信息 → 系统生成6位验证码 → 发送验证码邮件 → 用户输入验证码 → 验证成功 → 完成注册
```

### 2. 验证码验证流程

```
用户收到邮件 → 查看6位验证码 → 在验证页面输入 → 系统验证 → 验证成功/失败
```

## 使用说明

### 1. 用户操作

1. **注册账户**
   - 填写注册信息
   - 提交后自动跳转到验证页面

2. **验证邮箱**
   - 查看邮件中的6位验证码
   - 在验证页面输入验证码
   - 点击验证按钮完成验证

3. **重新发送**
   - 如未收到邮件，等待60秒后点击重新发送
   - 系统会生成新的验证码并发送

### 2. 管理员操作

1. **监控验证状态**
   - 查看用户邮箱验证状态
   - 处理验证失败的用户

2. **邮件配置**
   - 确保SMTP配置正确
   - 监控邮件发送成功率

## 故障排除

### 常见问题

1. **验证码收不到**
   - 检查垃圾邮件文件夹
   - 确认邮箱地址正确
   - 检查SMTP配置

2. **验证码过期**
   - 重新发送验证码
   - 检查系统时间是否正确

3. **验证失败**
   - 确认输入的是6位数字
   - 检查验证码是否过期
   - 确认没有多余的空格

### 调试方法

1. **查看日志**
   - 检查邮件发送日志
   - 查看验证失败原因

2. **测试邮件**
   - 使用测试脚本验证功能
   - 检查邮件配置

## 技术细节

### 验证码生成

```python
def generate_verification_code(length=6):
    """生成6位数字验证码"""
    return ''.join(secrets.choice(string.digits) for _ in range(length))
```

### 验证逻辑

```python
if (user.email_verification_code == verification_code and 
    user.email_verification_code_expires and
```
