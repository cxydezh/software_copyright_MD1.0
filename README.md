# 郑州医企创医疗科技有限公司 - 软著管理系统

## 项目简介

本系统是为郑州医企创医疗科技有限公司开发的软件著作权管理系统，主要包含两个部分：
1. **Web端**：面向用户和公司员工的业务管理平台
2. **桌面端**：面向项目执行者的专用工具

## 系统特色

- 致力于医疗知识产权保护和成果转化
- 专业做专利和软件著作权的设计、申请、转化
- 为医疗机构和企业搭建合作桥梁
- 让"医"务人员和"企"业共同"创"造

## 功能模块

### Web端功能
- **公司业务展示**：公司简介、服务项目、联系方式
- **用户管理**：注册、登录、项目申请、进度查询
- **业务员管理**：项目确认、立项、状态管理
- **执行者管理**：项目执行、完成确认、流水号更新
- **在线留言**：用户与员工之间的沟通平台

### 桌面端功能
- **项目管理**：本地项目同步、状态更新、归档
- **文件管理**：身份证PDF、统一社会信用代码证书PDF管理
- **模板管理**：申请材料模板、合同模板管理
- **工具集成**：网站快捷访问、流水号管理、数据备份

## 技术架构

### 后端技术
- **框架**：Flask 3.0
- **数据库**：MySQL（服务器端）+ SQLite（本地端）
- **ORM**：SQLAlchemy
- **认证**：Flask-Login
- **安全**：Flask-WTF（CSRF保护）

### 前端技术
- **框架**：Bootstrap 5.3.8
- **图标**：Font Awesome
- **样式**：响应式设计，移动端友好
- **交互**：原生JavaScript + AJAX

### 桌面端技术
- **GUI框架**：Tkinter
- **数据库**：SQLite
- **网络请求**：Requests
- **文件操作**：Python标准库

## 安装部署

### 环境要求
- Python 3.8+
- MySQL 5.7+ （Web端）
- Windows 10+ （桌面端）

### 安装步骤

1. **克隆项目**
```bash
git clone <repository-url>
cd Software_copyright_MS1.0
```

2. **安装依赖**
```bash
pip install -r requirements.txt
```

3. **配置数据库**
```bash
# 创建MySQL数据库
mysql -u root -p
CREATE DATABASE software_copyright CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

4. **配置环境变量**
```bash
# 复制配置文件
cp config/config.py.example config/config.py
# 编辑配置文件，设置数据库连接等
```

5. **启动Web应用**
```bash
python run_web.py
```

6. **启动桌面应用**
```bash
python run_desktop.py
```

## 使用说明

### Web端使用

1. **用户注册登录**
   - 访问 http://localhost:5000
   - 点击"注册"创建账户
   - 使用邮箱和密码登录

2. **项目申请**
   - 登录后进入用户中心
   - 点击"申请项目"填写项目信息
   - 提交申请等待审核

3. **员工操作**
   - 使用员工账户登录
   - 普通业务员：确认申请、立项管理
   - 项目执行者：接受项目、执行管理

### 桌面端使用

1. **身份认证**
   - 使用项目执行者账户登录
   - 系统会自动同步项目数据

2. **项目管理**
   - 查看分配的项目列表
   - 创建项目文件夹
   - 更新项目流水号

3. **文件管理**
   - 管理身份证PDF文件
   - 管理统一社会信用代码证书
   - 组织项目相关文件

4. **模板管理**
   - 使用申请材料模板
   - 复制合同模板到项目

## 业务流程

### 项目申请流程
1. 用户提交申请 → 2. 业务员确认 → 3. 立项审批 → 4. 执行者接受 → 5. 项目执行 → 6. 完成确认 → 7. 上传版权中心 → 8. 获取流水号 → 9. 证书完成 → 10. 项目结清 → 11. 项目归档

### 申请人类型
- **个人申请**：自然人申请，需身份证复印件
- **事业单位申请**：单位申请，需统一社会信用代码证书
- **联合申请**：事业单位+个人，需双方证件及合作协议
- **多人合作**：多个自然人，需所有人身份证复印件

### 业务类型
- **软件登记业务**：仅协助登记，不含开发
- **软件设计与登记**：包含设计开发，不含部署
- **软件部署与登记**：全流程服务，含开发、部署、登记

## 安全特性

- **会话管理**：安全的用户会话处理
