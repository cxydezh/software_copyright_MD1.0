# 选择对话框功能使用说明

## 🎯 快速开始

### 1. 数据库迁移（首次使用必须）

```bash
# 运行迁移脚本，添加recurrent_copy_time字段
python quick_migrate_local_db.py
```

### 2. 测试对话框功能

```bash
# 使用测试工具测试所有对话框
python test_selection_dialogs.py
```

### 3. 在桌面应用中使用

```bash
# 启动桌面应用
python run_desktop.py
```

## 📋 功能说明

### 模板选择对话框

**使用场景**: 为项目创建文件夹时选择并复制模板

**操作步骤**:
1. 在任务视图中选择一个项目
2. 点击"创建项目文件夹"按钮
3. 在对话框中浏览或搜索模板
4. 双击模板或点击"选择并复制"
5. 模板自动复制到项目文件夹，命名为`项目ID.项目名称`

### 身份证复印件选择对话框

**使用场景**: 向项目添加身份证复印件

**操作步骤**:
1. 在任务视图中选择一个项目
2. 点击"身份证复印件"按钮
3. 在对话框中浏览或搜索文件
4. 双击文件或点击"选择并复制"
5. 文件自动复制到项目文件夹

### 统一社会信用代码证书选择对话框

**使用场景**: 向项目添加统一社会信用代码证书

**操作步骤**:

2. 点击"统一社会信用代码证书"按钮
3. 在对话框中浏览或搜索文件
4. 双击文件或点击"选择并复制"
5. 文件自动复制到项目文件夹

### 合同文件选择对话框

**使用场景**: 向项目添加合同文件

**操作步骤**:
1. 在任务视图中选择一个项目
2. 点击"合同"按钮
3. 在对话框中浏览或搜索文件
4. 双击文件或点击"选择并复制"
5. 文件自动复制到项目文件夹

## 💡 使用技巧

### 快速查找
- 所有对话框都支持搜索功能
- 输入关键词后点击"检索"按钮
- 系统会自动定位并选中匹配的记录

### 最近使用
- 对话框会自动显示最近使用的10条记录
- 每次复制文件后，该文件会出现在"最近使用"列表顶部

### 文件名冲突
- 如果目标文件夹中已存在同名文件
- 系统会自动添加后缀（如 `文件_1.pdf`）
- 不会覆盖原有文件

## 🔧 故障排除

### 问题1: 数据库字段不存在

**错误信息**: `no such column: recurrent_copy_time`

**解决方法**:
```bash
python quick_migrate_local_db.py
```

### 问题2: 对话框显示为空

**原因**: 数据库中没有相关数据

**解决方法**:
- 先在材料管理或模板管理中添加数据
- 或导入示例数据

### 问题3: 文件复制失败

**可能原因**:
- 源文件不存在
- 目标文件夹没有写权限
- 磁盘空间不足

**解决方法**: 检查错误提示，根据具体原因处理
