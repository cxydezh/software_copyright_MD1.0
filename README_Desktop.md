# 软著管理系统 - 桌面客户端使用说明

## 系统要求
- Windows 10/11 (64位)
- 4GB RAM以上
- 500MB可用磁盘空间
- 稳定的网络连接

## 安装步骤

1. 解压缩下载的zip文件到任意目录
2. 双击运行"软著管理系统-桌面客户端.exe"
3. 首次运行会自动创建本地数据库和配置文件

## 配置服务器地址

首次使用需要配置服务器地址：

1. 打开应用后，进入"系统设置"
2. 在"服务器设置"中填入：
   - Web API地址: https://your-domain.com
   - Web API端口: 443
3. 点击"测试连接"确认连接正常
4. 点击"保存设置"

## 功能模块

1. **任务视图**: 项目管理、文件创建、流水号获取
2. **模板管理**: 软著申请文档模板管理
3. **材料管理**: 申请材料管理
4. **系统设置**: 路径配置、服务器设置

## 常见问题

### 无法连接服务器
- 检查网络连接
- 确认服务器地址配置正确
- 联系IT部门确认VPN连接

### 数据同步问题
- 确保与服务器连接正常
- 点击"刷新"按钮重新同步数据
